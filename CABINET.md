# Запуск на автомате

Игра — **один файл**: `crown-runner-standalone.html` (~3.4 МБ). Внутри уже лежит всё:
картинки, музыка, шрифт. Интернет не нужен ни при запуске, ни во время игры.

## Проверить, что интернета правда не нужно

Отключите Wi-Fi и откройте файл двойным щелчком. Игра должна работать полностью.
Если работает — на стенде тоже будет.

## Windows — самый простой путь

1. Скопируйте `crown-runner-standalone.html` на машину, например в `C:\crown\`.
2. Создайте рядом файл `Игра.bat` с одной строкой:

```bat
start "" "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --disable-pinch --overscroll-history-navigation=0 --disable-features=TranslateUI "file:///C:/crown/crown-runner-standalone.html"
```

3. Ярлык этого `.bat` положите в автозагрузку: `Win+R` → `shell:startup` → перетащите ярлык.

`--kiosk` — это и есть полный экран без вкладок, адресной строки и меню. Выход из
киоска — `Alt+F4`.

## macOS

```bash
open -a "Google Chrome" --args --kiosk "file:///Users/ВЫ/crown/crown-runner-standalone.html"
```

Автозапуск: **Системные настройки → Основные → Элементы входа** → добавить этот скрипт.

## Что настроить на самой машине

- **Сон и заставку — выключить.** Иначе автомат «умрёт» посреди выставочного дня.
- **Обновления Windows — отложить.** Перезагрузка в разгар дня хуже любого бага.
- **Автовход в систему без пароля**, иначе после перезагрузки автомат будет ждать человека.
- **Звук на 60–70 %** системный; внутриигровая громкость настраивается в самой игре
  (удержать SCAN три секунды → настройки).

## Если Chrome нет

Подойдёт любой современный браузер, флаг полноэкранного режима у каждого свой:
у Edge такой же `--kiosk`, у Firefox — `--kiosk`. Но Chrome проверен.

## Кнопки

Игра ждёт стандартную распайку MAME/RetroPie: `A`=LCtrl, `B`=LAlt, `C`=Space,
Start=`1`. Если энкодер шлёт другое — **удержать SCAN три секунды**, откроются
настройки, и там каждая кнопка переназначается прямо с панели, без клавиатуры.
